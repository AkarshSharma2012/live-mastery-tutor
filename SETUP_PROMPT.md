# Universal setup prompt

```text
Set up Live Mastery Tutor from https://github.com/AkarshSharma2012/live-mastery-tutor and start an isolated tutoring course for me.

Review the repository before installation. If Agent Skills and Node.js 22.20+ are available, install only the live-mastery-tutor skill with:
npx skills add AkarshSharma2012/live-mastery-tutor --skill live-mastery-tutor -g -y

If installation is unavailable, read skills/live-mastery-tutor/SKILL.md and only the references it routes to, then operate in connected-document or chat-only mode. Do not alter unrelated agent configuration.

Use local ./Learning state when possible. Do not connect accounts or write to external services without explicit approval. Ask for my learning goal, reason, current level, time budget, deadline, and available sources. Diagnose me one question at a time, propose a measurable course map, and wait for approval before teaching. Teach one concept at a time, require teach-back and authentic practice, preserve first-attempt scores, use spaced retrieval, and never mark mastery without the skill's evidence gates.
```
